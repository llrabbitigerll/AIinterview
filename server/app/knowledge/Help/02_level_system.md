## 公司级别映射（就低原则）

当一个公司级别横跨两个T级别时，取**低值**。

### 计算示例

- 阿里P7的薪资范围50-100w → 横跨T3(50-80w)和T4(60-120w) → 取低值 **T3**
- 京东P9的薪资范围100-200w → 横跨T5(100-180w)和T6(120-240w) → 取低值 **T5**
- 美团L8的薪资范围55-85w → 横跨T3(50-80w) → **T3**

## 面试轮次规则

### 单/双Agent触发

| 候选目标 | 第1轮 | 第2轮 | 第3轮 |
|--------|------|------|------|
| T1 | T1面试官/单Agent | T2面试官/单Agent | T3面试官/单Agent |
| T2 | T2/单 | T3/单 | T4/单 |
| T3 | T3/单 | T4/单 | T5/单 |
| T4 | T4/单 | T5/单 | T5/单 |
| T5 | T5/单 | T6/单 | **T7/双Agent** |
| T6 | T6/单 | **T7/双Agent** | **T8/双Agent** |

### 双Agent模式说明

- **单Agent模式**：仅Agent B（技术面试官）活跃
- **双Agent模式**：Agent B（技术面试官）+ Agent C（业务/战略面试官）交替提问
- 双Agent触发条件：由 `level_config.yaml` 中的 `round_rules` 决定
- 系统自动判断，不提供手动开关

### 决策树

```
输入: target_level + round
    ↓
查找 level_config.yaml → round_rules[target_level][round-1]
    ↓
获取 interviewer_level + mode
    ↓
mode == "single" → is_double_agent_mode = False
mode == "double" → is_double_agent_mode = True
```
